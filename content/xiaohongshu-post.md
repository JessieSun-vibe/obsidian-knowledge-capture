## 图文分镜

### 第 1 页：痛点

我以前收藏了很多小红书、YouTube、网页内容，但问题是：

- 收藏完就再也不看
- 好内容没有进我的知识库
- 想做账号内容时，很难调用过去看过的东西
- Obsidian 里有结构，但缺少自动化

所以我想做一个自己的“知识沉淀工作台”。

### 第 2 页：目标

我的目标不是单纯保存链接，而是让每条收藏自动变成可用素材：

```text
收藏内容
→ 进入 Obsidian Clippings
→ AI 自动整理
→ 归类到素材库
→ 后续做账号时直接调用
```

### 第 3 页：我做出来的效果

现在我保存一条内容后，它会自动变成这样的知识卡：

- 一句话总结
- 知识提炼
- 内容创作角度
- 来源内容
- 视频清理后的口播稿

并且会自动归类：

- AI
- 自媒体
- 美食
- 家居
- 投资
- 产品经理
- 职场成长
- 个人成长

### 第 4 页：输入来源

目前我接入了三类来源：

1. 小红书图文 / 视频
2. YouTube 视频
3. 普通网页 / 文章

平台不是重点，重点是它最后都会进入同一个素材库。

### 第 5 页：关键工作流

核心链路是：

```text
Obsidian Web Clipper
→ Clippings
→ Obsidian 插件监听
→ Codex Skill 处理
→ 生成知识卡
→ 删除原始剪藏
```

我没有一开始就做成大产品，而是先把自己每天真的会用的流程跑通。

### 第 6 页：Vibe Coding 的过程

这个系统不是我一次写完的，而是一边用一边改：

1. 先让 AI 看我的 Obsidian 结构
2. 定义我想要的知识卡格式
3. 做小红书 Clipper 模板
4. 做 Codex Skill
5. 做 Obsidian 自动触发插件
6. 测试 YouTube transcript
7. 把素材按主题自动归类
8. 最后沉淀成可分享的 GitHub 项目

### 第 7 页：我踩过的坑

几个关键坑：

- 小红书页面结构复杂，容易抓到无关内容
- 视频不能只靠标题和简介总结，必须有转写
- YouTube 有些视频拿不到 transcript
- 原始视频不应该长期保存在知识库里
- 自动化必须有失败状态，比如 `等待内容`、`等待图片`、`等待视频`

### 第 8 页：我最大的收获

这次让我更清楚地理解了 Vibe Coding：

不是“让 AI 一次性写出完美代码”，而是：

```text
明确自己的真实工作流
→ 拆成小步骤
→ 每一步和 AI 对齐
→ 真实测试
→ 不断修正
→ 最后形成自己的工具
```

### 第 9 页：适合谁

这套东西适合：

- 经常收藏内容的人
- 想做知识库但不想手动整理的人
- 做小红书 / 视频号 / 公众号的内容创作者
- 想用 Obsidian 搭建第二大脑的人
- 想学习 Vibe Coding 的非技术人

### 第 10 页：结尾 CTA

我把这套流程整理成了一个可安装项目。

它不会包含我的个人收藏和知识卡，只包含：

- Clipper 模板
- Obsidian 插件
- Codex Skills
- 自动化脚本
- 安装说明

如果你也想把收藏夹变成自己的素材库，可以从这个项目开始改成自己的版本。

## 正文版

我最近用 Vibe Coding 做了一个自己的 Obsidian 自动知识沉淀系统。

起因很简单：我收藏了太多小红书、YouTube 和网页内容，但大多数都躺在收藏夹里，没有真正进入我的知识库。等到我要做账号、写内容、找灵感时，又很难想起以前看过什么。

所以我想要的不是“保存链接”，而是让收藏自动变成可以调用的素材卡。

现在的流程是：

```text
小红书 / YouTube / 网页
→ Obsidian Web Clipper
→ Clippings
→ AI 自动整理
→ 按主题进入素材库
```

最终每条内容会变成结构化笔记，包括一句话总结、知识提炼、内容创作角度、来源内容。如果是视频，还会生成清理后的口播稿。

我现在按主题归类，比如 AI、自媒体、美食、家居、投资、产品经理、职场成长、个人成长。平台只作为来源属性，不决定文件夹。

这个过程最有意思的地方是，我不是一开始就知道怎么做，而是一边用一边和 AI 改出来的。先做最小流程，再不断解决真实问题：小红书抓取格式、YouTube transcript、视频是否要保存、失败状态怎么处理、原始剪藏怎么清理。

对我来说，这就是 Vibe Coding 最有价值的地方：不是为了写代码而写代码，而是把自己真实的工作流变成工具。

我也把这套流程整理成了一个可安装项目，里面只包含模板、插件、Skill 和脚本，不包含我的私人收藏和笔记。别人可以安装到自己的 Obsidian，然后生成自己的素材库。
